# לומדת מעבר להקבצה א׳ — מסלול עצמאי ב-3 שבועות

לומדה אינטראקטיבית ללימוד עצמי של חומר המעבר להקבצה א׳ במתמטיקה (כיתה ט׳):
- **שבוע 1:** פירוק לגורמים מאפס (חוק הפילוג המורחב, נוסחאות הכפל המקוצר, גורם משותף, טרינום ומשוואה ריבועית).
- **שבוע 2:** שברים אלגבריים ומשוואות רציונליות (תחום הצבה, צמצום, כפל וחילוק, משוואות עם משתנה במכנה ובעיות מילוליות).
- **שבוע 3:** גאומטריה (כתיבת הוכחה בטבלת טענה ונימוק, תכונות הדלתון ודלתון במערכת צירים, משפטים הפוכים במשולש שווה שוקיים ומשולש ישר-זווית 30°-60°-90°).

## הפעלה
- הלומדה פועלת בדפדפן גם במצב לא מקוון (התקדמות נשמרת אוטומטית במכשיר).
- ניתן להירשם ולהתחבר עם שם משתמש וסיסמה (ללא צורך בכתובת אימייל או פרטים אישיים) כדי לסנכרן את ההתקדמות בין מכשירים.
