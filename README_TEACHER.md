# מדריך למורה — ניהול חשבונות תלמידים, איפוס סיסמה והתראות

הלומדה שומרת לתלמידים חשבון אנונימי תחת שם משתמש בלבד (הממופה אוטומטית ב-Supabase לכתובת סינתטית מהצורה `<username>@students.app` — מכיוון ששרת ה-Auth של Supabase חוסם את הסיומת `.invalid` ברמת השרת).

## 1. נוהל איפוס סיסמה לתלמיד ששכח סיסמה

מכיוון שאין כתובת אימייל אמיתית לתלמידים, איפוס סיסמה מתבצע על ידי המורה מתוך ממשק הניהול של Supabase:

1. היכנסו ל-**Supabase Dashboard** ופתחו את פרויקט הלומדה.
2. בתפריט הצד לחצו על **Authentication** ולאחר מכן על **Users**.
3. בשדה החיפוש חפשו את שם המשתמש של התלמיד (יופיע תחת העמודה Email כ-`<username>@students.app`).
4. לחצו על שורת המשתמש או על תפריט שלוש הנקודות (`...`) בקצה השורה.
5. בחרו באפשרות **Update password** (או **Reset password / Set new password**).
6. הזינו סיסמה חדשה (לפחות 6 תווים), שמרו, ומסרו אותה לתלמיד.

---

## 2. הגדרת התראות בטלגרם (ומציאת ה-Chat ID)

פונקציית ה-Digest תומכת בשליחת הסיכום היומי והודעת ההרשמה המיידית לטלגרם (בנוסף או במקום וואטסאפ, בהתאם לסודות שמוגדרים בפרויקט).

### איך יוצרים בוט ומוצאים את ה-`TELEGRAM_CHAT_ID`:
1. בטלגרם, פתחו שיחה עם **`@BotFather`** ושלחו לו את הפקודה `/newbot`.
2. תנו לבוט שם ושם משתמש (חייב להסתיים ב-`bot`), ושמרו את ה-**Bot Token** שקיבלתם (`TELEGRAM_BOT_TOKEN`).
3. לחצו על הקישור לבוט החדש שלכם, לחצו **Start** ושלחו לו הודעה כלשהי (למשל `שלום`).
4. פתחו בדפדפן את הכתובת הבאה (החליפו את `<BOT_TOKEN>` בטוקן שקיבלתם מ-BotFather):
   `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
5. בתשובת ה-JSON שתופיע, חפשו את השדה `"chat":{"id":123456789,...}` — המספר שמופיע תחת `"id"` הוא ה-**`TELEGRAM_CHAT_ID`** שלכם.
   *(לחלופין, אפשר לשלוח הודעה לבוט `@userinfobot` בטלגרם והוא ישיב מיד עם ה-`Id` האישי שלכם).*
6. הגדירו את הסודות בטרמינל (מתוך תיקיית הפרויקט):
   ```powershell
   npx supabase secrets set TELEGRAM_BOT_TOKEN="הטוקן_מבוטפאדר" TELEGRAM_CHAT_ID="מספר_הצאט_שלכם"
   ```
