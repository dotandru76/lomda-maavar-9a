# מדריך למורה — ניהול הלומדה ב-Firebase, לוח בקרה חי ואיפוס סיסמה

הלומדה מחוברת לפרויקט ה-Firebase **`lomda-maavar-9a`** (Authentication + Cloud Firestore).
כל תלמיד נרשם עם שם משתמש וסיסמה בלבד (הממופה אוטומטית ב-Firebase לכתובת סינתטית `<username>@students.app`, ללא איסוף שם מלא או אימייל אמיתי).

---

## 1. לוח בקרה חי למורה (במקום תלות ב-CallMeBot)

בכתובת האתר קיים דף ייעודי למורה בלבד:
- **`teacher.html`** (למשל: `https://dotandru76.github.io/lomda-maavar-9a/teacher.html`)

### כניסה ראשונית ללוח הבקרה:
1. פתחו את `teacher.html`.
2. משתמש המורה המוגדר בחוקי האבטחה של Firestore הוא `teacher_admin`.
3. בכניסה הראשונה הקלידו סיסמה חזקה לבחירתכם (לפחות 6 תווים) ולחצו על **יצירת חשבון מורה ראשוני**.
4. מהפעם השנייה ואילך, הקלידו את הסיסמה ולחצו **כניסה**.

### מה מופיע בלוח הבקרה בזמן אמת:
- **סיכום יומי מוכן לשליחה (בפורמט המדויק):** לחצן **העתק סיכום** או **פתח בוואטסאפ** שפותח מיד הודעת וואטסאפ מוכנה עם סיכום 24 השעות האחרונות (נכנסו, חדשים, צעדים, בחנים, תרגילים, תקועים ולא פעילים 5+ ימים).
- **התראות דפדפן חיות:** לחיצה על **הפעל התראות דפדפן** תקפיץ התראה מיידית בכל פעם שתלמיד חדש נרשם בזמן שהדף פתוח.
- **טבלת התקדמות מלאה של כל התלמידים** + **יומן אירועים חי**.

---

## 2. נוהל איפוס סיסמה לתלמיד ששכח סיסמה

איפוס או מחיקת משתמש מתבצעים מתוך ממשק הניהול של Firebase:

1. היכנסו ל-[Firebase Console](https://console.firebase.google.com/) ופתחו את פרויקט **`lomda-maavar-9a`**.
2. בתפריט הצד לחצו על **Build → Authentication** ועברו ללשונית **Users**.
3. אתרו את התלמיד לפי שם המשתמש שלו (`<username>@students.app`).
4. לחצו על תפריט שלוש הנקודות (`⋮`) בקצה השורה:
   - אם ברצונכם לאפשר לתלמיד להירשם מחדש עם אותו שם משתמש וסיסמה חדשה: בחרו **Delete account** (מסמך ההתקדמות שלו ניתן לשחזור או שייווצר מחדש עם ההתחברות).
   - לחלופין, בשימוש ב-Firebase Admin CLI ניתן להגדיר סיסמה חדשה ישירות לפי ה-`User UID`.
